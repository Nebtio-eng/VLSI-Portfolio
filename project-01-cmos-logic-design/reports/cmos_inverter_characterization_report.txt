# CMOS Inverter Engineering Report

## Project

Project 01 — CMOS Logic Design from First Principles

---

## Objective

Design, simulate, and characterize a CMOS inverter using LTspice and automate the characterization workflow using Python.

---

- 5 V

Simulation Types

- DC Sweep
- Transient Analysis

- Static
- Timing
- Power

## Engineering Observations

- Rail-to-rail switching was achieved.
- The inverter exhibits a sharp transition region.
- The NMOS pull-down path switches faster than the PMOS pull-up path.
- Python automation successfully generated all characterization reports.

---

## Conclusion

The CMOS inverter was successfully implemented, simulated, and characterized. The automation framework developed in this project will be reused for all remaining CMOS logic gates.
